# diagnostico-ambiental-mancilla
Diagnóstico básico de la calidad del agua del Embalse Mancilla en Facatativá mediante interpolación lineal.
PROCESO REALIZADO
## Proceso realizado

El desarrollo del proyecto se realizó mediante herramientas de programación, análisis de datos y control de versiones.

### Etapas desarrolladas

1. Se creó un repositorio en GitHub para almacenar y gestionar el proyecto.

2. El repositorio fue clonado en el computador utilizando Git Bash.

3. El proyecto fue abierto y trabajado en Visual Studio Code.

4. Se creó la estructura principal del proyecto mediante carpetas para:
   - datos,
   - notebooks,
   - informe,
   - imágenes.

5. Se organizaron archivos CSV con información ambiental relacionada con:
   - agua,
   - clima,
   - residuos,
   - vegetación.

6. Se desarrollaron notebooks en Jupyter para el análisis de cada componente ambiental.

7. Se utilizaron librerías de Python como:
   - pandas,
   - matplotlib.

8. Se realizaron:
   - estadísticas básicas,
   - gráficas,
   - análisis de variables,
   - interpretación ambiental.

9. Se aplicó interpolación lineal como método numérico para estimar valores intermedios entre datos conocidos.

10. Se implementaron estructuras condicionales en Python para generar interpretaciones automáticas de algunas variables ambientales.

11. Todos los cambios realizados fueron guardados mediante Git Bash utilizando:
   - git add
   - git commit
   - git push

12. Finalmente, el proyecto fue integrado y actualizado en GitHub como repositorio principal del diagnóstico ambiental.
